## 既知の問題

- Safariでは、ブラウザのタブで起動した場合と、アプリ(Dock/ホーム画面に追加)として起動した場合でlocalStorageが分離され、セーブデータが共有されません。
  - 引き継ぐ場合は、ゲーム内設定の「DAILY DATA」「QUEST DATA」それぞれを「Export」で書き出し、移行先で「Import」で復元してください。
